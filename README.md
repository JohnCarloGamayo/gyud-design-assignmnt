# Command Center: Unified Merchant Analytics

This is a premium React-based dashboard built for the Gyud Technologies design assignment. It provides merchants with a unified view of their Shopify and TikTok Shop data, specifically focusing on inventory health and multi-channel performance.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone [your-repo-link]
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack
- **Framework**: React 18 (Vite)
- **Icons**: Lucide React
- **Charts**: Recharts
- **Styling**: Vanilla CSS (Global variables & Component-based modules)
- **Routing**: React Router DOM

## 📐 Architecture
The project follows a modular component architecture:
- `/src/components`: Reusable UI elements (Modal, Toast, Layout).
- `/src/pages`: Feature-specific views (Dashboard, Analytics, Inventory, etc.).
- `/src/hooks`: Shared logic for data fetching and simulation.
- `/src/styles`: Global design tokens and resets.
